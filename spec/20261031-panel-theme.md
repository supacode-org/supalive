# 介面主題：浮起面板風格

## 摘要

主題改用一份控制面板風格包的風格（macOS / iOS 26 下 Proxyman 式的資料工具介面），可以保留一點點特定取色。

整體視覺改成這套風格：淺灰畫布上放浮起的圓角面板，層次靠底色和陰影，不靠描邊；控制項是膠囊和填充色；系統字體、緊湊的字級。抖音的取色只留在跟錄製和直播有關的少數地方。

## 原則

- 面板浮在畫布上：實心底色、圓角 14px、淡陰影，面板之間留 8px，這 8px 同時是拖曳欄寬的把手。面板、卡片、按鈕都不加描邊，只有面板內部的分隔用 1px 細線。
- 畫布可以疊兩團極淡的藍、紫色光（左上、右上各一團徑向漸層，透明度 5–7%）。色光只放在畫布上，不進面板。
- 控制項用填充、不用描邊：靜止 `fill`，懸停 `fill-strong`。
- 顏色一律取 token。淺色、深色兩套 token 一一對應，主題只靠替換 token 切換。
- 一個區域最多一個實心強調色按鈕。

## 保留的抖音取色

只有這幾處，其他地方一律用下面的 token：

| 用途 | 色值 |
| --- | --- |
| 「開始錄製」「停止」等錄製按鈕 | 抖音紅 `#FE2C55`，懸停 `#D21B46` |
| 錄製中：側欄脈衝點、REC 標籤、「回到直播」、錄製中標籤 | 直播漸層 `#FF1764 → #ED3495`，文字用 `#FF1764` |
| 影片上的 LIVE 標籤 | 直播淺藍 `#8CE7FF` |
| 影片區底色 | `#161616`，兩個主題相同 |

陰影：

- 面板：淺色 `0 0 0 .5px rgba(0,0,0,.08), 0 1px 2px rgba(0,0,0,.04), 0 6px 18px rgba(0,0,0,.04)`；深色 `0 0 0 .5px rgba(255,255,255,.08), inset 0 .5px 0 rgba(255,255,255,.07), 0 2px 10px rgba(0,0,0,.35)`。
- 浮層：淺色 `0 14px 44px rgba(0,0,0,.16), 0 0 0 .5px rgba(0,0,0,.12)`；深色 `0 16px 48px rgba(0,0,0,.55), 0 0 0 .5px rgba(255,255,255,.1)`。

## 字型與尺寸

- 系統字體，等寬字用於路徑、時間、大小、編碼；數字加 `tabular-nums`。
- 字級只有 15 / 13 / 12 / 11 四檔：頁面與對話框標題 15、正文 13、控制項與列表 12、標籤與小標題 11。小標題 600 字重、字距 0.025em。
- 圓角：按鈕、分段、標籤、開關全圓角；輸入框 8px；列表懸停與選中 6px；對話框裡的分組卡片 16px；面板 14px；對話框 22px。
- 控制項高度：預設 32px，sm 28px。

## 元件

- **按鈕**：預設是 `fill` 填充；`ghost` 透明、懸停 `fill`；`primary` 藍色實心；錄製按鈕抖音紅實心；刪除確認 `destructive` 實心。按下縮到 0.97。
- **圖示按鈕**：圓形、透明、懸停 `fill`。影片上的控制列維持半透明白色。
- **標籤**：高 18px、全圓角、11px，同色 10% 淡底加 25% 內描邊；待錄製用中性的 `fill` 底灰字。
- **側欄項目**：懸停 `fill`，選中 `selection` 實心藍底白字。
- **輸入框**：`fill` 底、無描邊；聚焦時換成面板底色加焦點環。
- **開關**：36 × 20，關閉 `fill-strong`，打開 `primary`，白色圓鈕。
- **分段（新增直播間的頁籤）**：`fill` 膠囊凹槽，選中項是浮起的白色膠囊；深色時是 16% 白。
- **對話框**：`popover` 底加模糊、圓角 22px、浮層陰影。設定的各列放在 `card` 分組卡片裡，行間細線從內容起點開始。
- **提示（toast）**：`popover` 底加模糊與浮層陰影。
- **警告橫幅**：`st-abnormal` 10% 淡底、25% 內描邊。
- **抖音側欄的畫質清單**：選中用 `primary`。

## 原生材質與省電模式

- 有原生視窗材質（macOS Liquid Glass / vibrancy、Windows Mica）時，畫布半透明讓材質透出來；面板維持實心。
- 省電模式和系統「減少透明度」：畫布改實心、關掉色光，浮層的模糊也關掉，改用實心底。

## 驗證

- 淺色、深色各截圖一次：首頁（錄製中、已結束、待錄製）、播放器頁、新增直播間、設定、抖音側欄的畫質清單。
- 在 Leo 的 Mac 上開原生材質看一次畫布透出的效果；Windows 建置後看 Mica。

## 不在範圍內

- 版面結構（欄位、標題列高度）不變。
- 介面文字不變。
