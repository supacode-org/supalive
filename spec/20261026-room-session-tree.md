# 首頁：直播間與錄製兩級樹狀結構

## 摘要

首頁改成兩級樹狀結構：直播間為第一級，它的每次錄製為第二級，之後管理起來比較方便。

## 資料

資料本來就是兩級：`get_state` 回傳的 `rooms[]`，每個都有 `recordings[]`，舊的在前。正在錄的那一次一定是 `recordings` 的最後一個。

## 針對單次錄製的指令

| 指令 | 參數 | 說明 |
| --- | --- | --- |
| `merge_recording` | `{ id, index? }` | 合併第 `index` 次錄製（`recordings` 的位置，從 0 起算）。沒給 `index` 時合併最近一次 |
| `remove_recording` | `{ id, index }` | 從清單移除一次錄製，檔案留在原本的資料夾 |

- 直播間有錄製或合併在進行時，`remove_recording` 會回錯誤。錄製和合併的事件用位置找紀錄，進行中時移除會讓位置錯開。
- 直播間層級的指令照舊：`start_recording`、`stop_recording`、`remove_room`、`update_room`。

## 介面

首頁標題是「直播間」，副標題寫直播間數、正在錄製的數量與輸出位置。

**第一級：直播間**

- 錄製中的排最前面，其餘依最近一次活動（最後一次錄製的結束或開始時間，沒錄過就用加入時間）排，新的在前。
- 一列顯示：
  - 收合按鈕（有錄製紀錄時才有）；
  - 名稱，底下是主播、畫質、錄製次數、連結到期時間；
  - 錄製中或合併中時的狀態標籤；
  - 「開始錄製」（錄過的叫「再錄一次」；連結過期或合併中時不能按）或「停止」；
  - 移除直播間。

**第二級：每次錄製**

- 新的在前，預設只列最近 3 次，多的收在「顯示全部 N 次錄製」後面。
- 正在錄的那一次：即時預覽（見 [`20261026-live-card-preview.md`](20261026-live-card-preview.md)）加上開始時間、時長、大小、分段、碼率和分段進度。點預覽進入播放器頁。
- 已結束的：開始時間，底下是時長、大小、分段數；合併狀態標籤；播放、合併（有分段且還沒合併時）、打開資料夾、從清單移除。合併中時只顯示標籤。
- 從清單移除前先確認，對話框裡列出檔案所在的資料夾。

**播放器頁**

- 從某次錄製的「播放」進來，播放器頁就顯示那一次：標題旁寫開始時間，檔案樹和檔案列表都是那一次的。從直播間或即時預覽進來時顯示最近一次。
- 開始和停止錄製的按鈕看的是直播間目前的狀態，跟正在看哪一次無關。

## 驗證

- 同一個直播間錄兩次，首頁在同一個直播間底下列出兩次錄製。
- 合併、移除較早的那一次，不影響另一次。
- 正在錄的直播間，移除它底下的錄製會被擋下並顯示原因。

## 不在範圍內

- 移除錄製時一併刪除檔案。
- 改變錄製紀錄的儲存格式（`supalive.json`）。

## 更新：刪除會連檔案一起刪，並檢查檔案還在不在（2026-10-26）

- 刪除預設移到廢紙簍，下面放一個預設不勾的永久刪除。
- 使用者已經自己刪掉檔案時，不能還顯示檔案在，要寫找不到。

這裡取代上面「從清單移除，檔案留在原本的資料夾」的做法，「不在範圍內」的「移除錄製時一併刪除檔案」也不再適用。

### 刪除

- 刪除一次錄製：整個錄製資料夾預設移到廢紙簍（Windows 是資源回收筒），再從清單拿掉。
- 刪除直播間：它所有錄製的資料夾都移到廢紙簍，再從清單拿掉。中途有一次刪不掉時停下來；已經刪掉的錄製從清單拿掉，其餘留著，清單和磁碟保持一致。
- 對話框裡有「永久刪除，不放進廢紙簍」，預設不勾。勾選後顯示「永久刪除後無法復原」，按鈕變成「永久刪除」。
- 只刪錄製紀錄裡記下的資料夾，刪之前檢查：
  - 必須是絕對路徑；
  - 不能是輸出位置本身或它的上層；
  - 裡面要有 `clips/`、`merged/` 或 `cover.jpg`。
  
  不符合就不刪並顯示原因。
- 刪完後直播間的資料夾如果空了（只剩 `.DS_Store` 之類的系統檔），一起清掉；輸出位置本身不動。
- 移到廢紙簍用 `trash` 套件（MIT）。macOS 上用系統的 `NSFileManager`：不會跳出「要控制 Finder」的權限要求，上架版也能用；但部分系統上，廢紙簍裡沒有「放回原處」，要自己拖回來。
- 刪除檔案在背景執行緒做，永久刪除大檔案時介面不會卡住。

### 檔案找不到

- `get_state` 多回傳 `present`：以直播間編號為鍵，和 `recordings` 一一對應，內容是 `{ dir, missing }`：
  - `dir` 表示錄製資料夾還在不在；
  - `missing` 是紀錄裡有、但找不到的分段和合併檔。
- 資料夾不見：那次錄製顯示「找不到檔案」，說明「找不到錄製資料夾，可能已被移動或刪除」，只剩刪除，按下去只從清單拿掉。
- 部分檔案不見：顯示「N 個檔案找不到」，播放、合併只用還在的檔案。播放器頁的檔案清單把找不到的標出來，不能點。
- 檔案都不見時，播放器頁直接說找不到，不會顯示「系統 WebView 無法播放」。
- 手動合併只合併還在的分段。
- 切回 App（視窗取得焦點）時重新檢查。結果沒變就不重繪，正在播的檔案不會被打斷。
