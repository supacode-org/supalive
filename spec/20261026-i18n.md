# 介面語言：正體中文與英文

## 摘要

介面支援正體中文和英文，依作業系統的語言決定，預設正體中文。

另外確認過：

- 範圍是整個桌面版：
  - 介面；
  - 後端回傳的錯誤訊息；
  - 錄製核心送到介面的狀態（斷線原因、警告）。
- 命令列暫時維持中文。
- 設定裡加手動切換，預設跟隨系統。

## 決定用哪種語言

- 設定「語言」有三個選項：跟隨系統（預設）、正體中文、English。存在 `supalive.json` 的 `lang`，值為 `system`、`zh-Hant`、`en`。
- 跟隨系統時，依序看系統的偏好語言（WebView 的 `navigator.languages`），取第一個中文或英文：
  - 中文（不分繁簡）用正體中文；
  - 英文用 English；
  - 都沒有時用正體中文。
- 切換後介面立刻重繪，不用重開 App。

## 後端與錄製核心

- 介面在啟動和切換語言時呼叫 `set_locale { lang }`，告訴後端目前用哪種語言。
- 後端和錄製核心產生給人看的訊息時，依這個設定選中文或英文：
  - 指令回傳的錯誤；
  - 斷線原因；
  - 警告；
  - 合併失敗等。
- 命令列不呼叫 `set_locale`，維持中文。
- 已經存進 `supalive.json` 的文字不改寫，例如畫質「原畫」、最後一次斷線原因：
  - 畫質名稱在介面上顯示時再翻譯；
  - 斷線原因照當時的語言顯示。
- 沒有名稱的直播間，資料夾名稱跟著語言：中文「未命名直播間」，英文「Unnamed room」。

## 用詞

| 中文 | English |
| --- | --- |
| 直播間 | room |
| 錄製 | recording |
| 分段 | segment |
| 合併 | merge |
| 選取直播 | Live Picker |
| 邊錄邊看 | Watch live |
| 原畫／藍光／超清／高清／標清 | Original / Blu-ray / Super HD / HD / SD |
| 抖音 | Douyin |

## 驗證

- 系統語言設成英文，打開 App 是英文；設成中文（含簡體）或其他語言是正體中文。
- 設定裡切換語言，介面立刻換，重開後保留。
- 英文介面下：
  - 斷線、找不到抖音網址等錯誤訊息是英文；
  - 舊錄影的畫質名稱顯示成英文。
- 兩種語言下版面都沒有被長字串撐破：首頁、播放器頁、設定、新增對話框、選取直播。

## 不在範圍內

- 命令列的輸出和 `--help`。
- 其他語言。
- spec 和開發文件。
