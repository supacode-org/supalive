# 發佈版本

## 摘要

在 GitHub 上發佈版本，提供 macOS 和 Windows、arm64 和 x86_64 的安裝檔，全部在本機（Apple Silicon Mac）打包。發佈成功後版本號自動加一，整個流程整理成可以重複執行的步驟。

## 產物

打包結果放在 `dist/v<版本>/`（不提交），發佈時附在同名的 GitHub Release 上：

| 平台 | 架構 | 桌面版 | 命令列 |
| --- | --- | --- | --- |
| macOS | Apple Silicon | `SupaLive_<版本>_aarch64.dmg` | `supalive-cli_<版本>_macos-aarch64.zip` |
| macOS | Intel | `SupaLive_<版本>_x64.dmg` | `supalive-cli_<版本>_macos-x86_64.zip` |
| Windows | x64 | `SupaLive_<版本>_x64-setup.exe` | `supalive-cli_<版本>_windows-x86_64.zip` |
| Windows | ARM64 | `SupaLive_<版本>_arm64-setup.exe` | `supalive-cli_<版本>_windows-aarch64.zip` |

- macOS Intel 版交叉編譯。
- Windows 兩種架構用 Tauri 的交叉編譯（`--runner cargo-xwin`）打包。這是 Tauri 標示為實驗性的做法，只出 NSIS 安裝檔。安裝程式依系統語言顯示正體中文或英文。
- 發佈包裡沒有 ffmpeg。

## 本機需要的工具

只需要裝一次：

```sh
rustup target add x86_64-apple-darwin x86_64-pc-windows-msvc aarch64-pc-windows-msvc
brew install nsis llvm lld
cargo install --locked cargo-xwin
cargo install tauri-cli --version "^2" --locked
```

makensis 在 C locale 下會當掉，`tools/release.sh` 打 Windows 版時會設 `LC_ALL=en_US.UTF-8`。

`cargo-xwin` 第一次執行時會下載 Microsoft 的 CRT 與 Windows SDK，等於同意 Microsoft 對這些元件的授權條款。

## 版本號

- 只有一個來源：根目錄 `Cargo.toml` 的 `[workspace.package] version`。`tauri.conf.json` 不寫版本號，Tauri 會讀 `Cargo.toml`。
- 發佈成功後，修訂號加一（`0.1.0` → `0.1.1`），提交並推上 `main`。下一次發佈就用這個版本號；要升次版本號或主版本號時，發佈前手動改。

## 簽名

暫時沒有 Apple Developer ID 和 Windows 程式碼簽章憑證：

- macOS 版用 ad-hoc 簽名。第一次打開會被 Gatekeeper 擋下，要到「系統設定 → 隱私權與安全性」按「強制打開」。
- Windows 版沒有簽名，SmartScreen 會提醒，按「其他資訊 → 仍要執行」。
- Release 說明裡寫上這兩點。

## 流程

`tools/release.sh` 分兩步，中間可以先試裝：

1. `tools/release.sh build`
   - 檢查：在 `main`、工作區乾淨、和 `origin/main` 同步、這個版本的 tag 還不存在。
   - 跑 `cargo fmt --all --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace`。
   - 打包四個平台的桌面版和命令列，放進 `dist/v<版本>/`。
2. `tools/release.sh publish <說明檔>`
   - 再檢查一次，並確認 `dist/v<版本>/` 裡八個檔案都在。
   - 建立並推送 tag `v<版本>`，建立 Release，上傳八個檔案。
   - 版本號加一，更新 `Cargo.lock`，提交並推送。

## 驗證

- 第一次發佈 `v0.1.0`：八個檔案都在 Release 上。
- 在 Leo 的 Mac 上安裝 Apple Silicon 的 dmg，能打開並錄製。
- Windows 版至少在一台 x64 機器上安裝、打開（交叉編譯的產物在 Mac 上無法執行，要在 Windows 上試）。

## 不在範圍內

- Apple 公證與 Windows 程式碼簽章。
- App 內自動更新。
- 在 CI 上建置。
- Linux 安裝檔。
- App Store 版（`tools/build-appstore.sh`）。
