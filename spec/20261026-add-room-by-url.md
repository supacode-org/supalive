# 用直播間網址新增直播間

## 摘要

新增直播間不再貼拉流網址，改成貼直播間網址：右側內嵌抖音網頁版的側欄（介面上叫「選取直播」）跳過去，自動抓到各種畫質的拉流網址後列出來。使用者可能會在頁面上切換畫質，所以各路網址先短暫保留，使用者選定並確認之前什麼都不動，確認後才開始錄製。

## 貼上網址

- 新增對話框只收直播間網址，按「前往直播間」（或 Enter）後關閉對話框、打開「選取直播」跳過去。
- 可以貼：
  - 直播間網址，例如 `https://live.douyin.com/123456`；
  - 抖音 App「分享」複製出來的整段文字，裡面有 `https://v.douyin.com/xxxx/` 短網址。
- 介面呼叫 `douyin_open { bounds, url: 貼上的文字 }`：
  - 從文字裡找出第一個抖音網域的 https 網址；
  - 打開側欄並跳過去，側欄已經開著時也跳過去；
  - 找不到網址時回傳錯誤訊息，介面直接顯示。

## 抓取各種畫質

- 注入腳本把直播間資料裡的每一種畫質都回報上來，抓得到時附上解析度。頁面播放器實際在拉的那一路也會回報。
- 後端依直播間（`webRid`）暫存候選網址：
  - 只放在記憶體裡；
  - 30 分鐘沒有新回報就丟掉；
  - 過期（網址的 `expire`）的移除；
  - 同一路的網址重新簽名時，用新的取代舊的。
- 只收這個直播間的串流。抖音是單頁應用，從首頁點進直播間後，頁面資料裡還留著許多推薦直播間的網址。
  - 同一個直播間的各種畫質，網址最後一段的串流名稱相同，只差畫質後綴（例如 `stream-123_or4.flv`、`stream-123_hd.flv`）。
  - 以頁面播放器實際在拉的那一路為準；播放器還沒開始拉時，先用直播間資料 API 回報的第一路。名稱不同的都丟掉。
  - 從頁面文字裡掃到的網址只用來補齊同一個直播間的畫質，不會決定是哪個直播間。
- 使用者在抖音頁面上切換畫質時，頁面正在播的那一路會被標記出來；切回之前播過的畫質也會更新。
- 每次有新回報，後端送出事件 `douyin-streams`，內容是該直播間的完整清單。介面也可以用 `douyin_streams { webRid? }` 讀取，沒給 `webRid` 時回傳最近有回報的直播間。

```json
{
  "webRid": "123456", "anchor": "主播名", "pageUrl": "https://live.douyin.com/123456", "userAgent": "…", "updated": 1761400000000,
  "streams": [
    { "url": "https://…_or4.flv?…", "quality": "origin", "label": "原畫", "resolution": "1080x1920", "source": "api", "playing": false, "expire": 1761500000 },
    { "url": "https://…_sd.flv?…",  "quality": "SD1",    "label": "高清", "resolution": null,        "source": "fetch", "playing": true, "expire": 1761500000 }
  ]
}
```

- `streams` 依畫質由高到低排好：原畫、藍光、超清、高清、標清。
- `quality` 是抖音的畫質代號，頁面播放器的網址可能沒有。
- `label` 是給人看的畫質名稱。
- `playing` 表示頁面現在播的那一路。

## 選定與確認

- 「選取直播」下方列出候選畫質（單選），每一路顯示畫質名稱、解析度，頁面正在播的那一路標「頁面播放中」。
- 預設選中的那一路：
  - 使用者在列表裡點過，就用點的那一路；
  - 沒點過時跟著頁面正在播的那一路，所以在抖音頁面上切換清晰度也等於在選；
  - 頁面還沒開始播時用最高畫質。
- 使用者確認之前不加入清單、不開始錄製。確認有兩種：
  - 「錄製這個畫質」：依序呼叫 `add_room { url, headers: [["Referer","https://live.douyin.com/"],["User-Agent", userAgent]], anchor, name: anchor, webRid }` 和 `start_recording`。同時錄製超過 2 個時，照樣先跳提醒；
  - 「只加入清單」（直播間已在清單裡時是「更新網址」）：只呼叫 `add_room`。
- 直播間已經在錄製時不顯示這兩個按鈕。
- 畫質清單限高、可以捲動，下方整塊區域也有高度上限，不會把上面的抖音頁面擠掉。有新回報重繪時保持原本的捲動位置。
- 抖音網頁版是單頁應用，在頁面裡切換直播間不一定會觸發頁面載入。側欄以最新一次回報的直播間為準，網址列也跟著它的 `pageUrl` 更新。

## 拿掉的舊流程

- 貼拉流網址或 cURL 指令的新增方式，以及它用的 `parse_input` 指令。
- 逐筆回報的 `douyin-stream` 事件，由 `douyin-streams` 取代。
- 核心的 cURL 解析（`supalive_core::curl`）留著，CLI 還在用。

## 驗證

以下都要在 Leo 的 Mac 上測：

- 貼上直播間網址和 App 分享文字，側欄都能跳到直播間，並列出多種畫質。
- 在抖音頁面上切換清晰度，正在播的標記跟著換。
- 沒按確認之前，清單和錄製都沒有變化。
- 確認後錄製的是選定的那一路畫質。

## 不在範圍內

- 抖音以外的平台。
- 用暫存的候選網址自動更新過期的錄製連結。

## 更新：連結過期時重新抓取（2026-10-26）

連結已過期的直播間，也要有一個按鈕跳回它的直播間，用來抓取最新的連結。

- 首頁直播間那一列，連結已過期、而且沒有在錄製時，在「開始錄製」旁邊多一個「重新抓取連結」。
- 按下去打開「選取直播」，跳到 `https://live.douyin.com/<webRid>`。
- 抓到畫質後照一般流程選一路：
  - 「更新網址」只換掉這個直播間的拉流網址；
  - 「錄製這個畫質」換掉網址並開始錄製。
- 需要直播間的 `webRid`，從「選取直播」加入的直播間才有。以前貼拉流網址加入的沒有，不顯示這個按鈕。
