# 輸出目錄：直播間名/時間

## 摘要

配合首頁的直播間與錄製兩級結構（見 [`20261026-room-session-tree.md`](20261026-room-session-tree.md)），輸出目錄也改成「直播間名/時間/…」兩層。這次改動取代 `docs/HANDOFF.md`「錄製預設值」裡原本的「直播間名_時間」一層結構。

## 結構

```
<根目錄>/<直播間名>/<yyyy-mm-dd-hh-mm>/
├─ clips/
├─ cover.jpg
└─ merged/<直播間名>_<yyyy-mm-dd-hh-mm>.mp4
```

- 根目錄預設仍是 `~/Downloads/SupaLive`。
- `cover.jpg` 是介面留下的封面，見 [`20261026-recording-cover.md`](20261026-recording-cover.md)。
- 讀不到直播間名稱時，放在 `未命名直播間/` 底下。
- 合併檔名帶直播間名，搬離資料夾後也看得出是哪一場。
- 同一個直播間在同一分鐘開始兩次錄製時，時間資料夾加上 `_2`、`_3`。

## 直播間名稱當資料夾名

- 檔名不允許的字元換成底線，跟以前一樣。
- 去掉結尾的句點和空白（Windows 不接受）。
- 處理後是空字串、`.` 或 `..` 時，改用 `未命名直播間`，不會建到根目錄外面。
- Windows 的保留裝置名稱（`CON`、`PRN`、`AUX`、`NUL`、`COM1`–`COM9`、`LPT1`–`LPT9`）後面加底線。

## 舊錄影

- 已經存在的錄影留在原處，不搬移。`recordings[].dir` 記的是實際路徑，照常可以播放和合併。
- 手動合併時，合併檔名依資料夾推回：
  - 新結構接起兩層名稱；
  - 舊結構直接用資料夾名稱。

## 介面文字

設定對話框「輸出位置」的說明和範例樹改成新結構。

## 驗證

- 單元測試：兩層結構、同一分鐘的 `_2`、沒有名稱和不安全的名稱都留在根目錄底下、舊結構的合併檔名。
- 在 Mac 上錄一場，確認資料夾和合併檔名。

## 不在範圍內

- 搬移或重新命名既有的錄影。

## 更新：沒有名稱的資料夾跟著介面語言（2026-10-26）

介面加了英文（見 [`20261026-i18n.md`](20261026-i18n.md)）。英文介面下，沒有名稱的直播間放在 `Unnamed room/` 底下，中文介面維持 `未命名直播間/`。已經建好的資料夾不改名。
