# 抖音介面與色卡研究

目的：之後改善 SupaLive 介面時參考。這份只記錄觀察和可選方向，還沒有決定要改什麼。

## 來源與方法

- 2026-10-26 在內建瀏覽器打開 `www.douyin.com`（推薦頁）和 `live.douyin.com`（直播首頁），讀取 `:root` 的計算後 CSS 變數，並抓 `static-style.*.css` 裡淺色 `:root` 與深色 `:root[dark]` 兩組原始定義。
- 元件尺寸是用 `getComputedStyle` 量實際元素得到的。
- 抖音網頁版的變數命名（`--semi-*`、`color-bg-b0`、`color-text-t1`）跟字節跳動開源的 [Semi Design](https://semi.design/zh-CN/basic/tokens) 同一套體系。
- **不計入採色**：左上角的抖音 logo（青 `#25F4EE` + 紅 `#FE2C55` 疊影）。青色 `#25F4EE` 只出現在 logo，抖音介面元件本身幾乎不用它。
- 第三方整理的 TikTok 品牌色（Razzmatazz `#FE2C55`、Splash `#25F4EE`、黑、白）見 [brandcolorcode](https://www.brandcolorcode.com/tiktok)，但那不是抖音官方規範，只供對照。

## 一、整體印象

1. **只有一個強調色**：抖音紅 `#FE2C55`。其他幾乎都是中性灰階。選中分頁的底線、主要按鈕、紅色標籤都用它。
2. **深色優先**：網頁版預設深色（`<html dark="true">`），內容是影片，介面退到後面。
3. **文字分層靠透明度**：深色模式下文字是白色加 0.9／0.75／0.6／0.34 的透明度，不是幾個不同的灰色。淺色模式則是 `#161823` 加同樣的透明度。
4. **底色分層靠明度**：b0 → b3 一階比一階亮，不用陰影或描邊分層。
5. **「直播中」有專屬漸層**：`#FF1764 → #ED3495`，跟主色紅區分開。
6. **錯誤色是橙紅不是主色紅**：`danger` 是 `#FF4C13`，避免和品牌紅混淆。

## 六、跟 SupaLive 目前的差異

目前的變數在 `apps/desktop/ui/styles.css` 開頭。

| 項目 | SupaLive 現在 | 抖音 |
| --- | --- | --- |
| 強調色 | 青 `--cyan`（`#00A7B3`／`#25F4EE`）當主要按鈕、進度條、焦點框 | 只用紅 `#FE2C55`；青色只在 logo |
| 錄製紅 | `--rec` `#F0244F`／`#FF4B6E` | 主色 `#FE2C55`；直播狀態另用粉紅漸層 |
| 桌布色塊 | `--w1`～`--w4` 藍、粉、青、黃四色 | 沒有彩色背景，全中性 |
| 深色底 | `#090B12`（幾乎黑、偏藍） | `#161823`（帶藍）或 `#161616`（純灰） |
| 次要文字 | 實色灰 `#596277`／`#9AA3B6` | 主文字色加透明度（.75／.6／.34） |
| 成功／警告 | `#11845A`／`#A85F00`（淺色偏暗沉） | `#13C15A`／`#FF851D`，兩個模式同一個色值 |
| 錯誤 | 沿用 `--rec` | 獨立的橙紅 `#FF4C13` |
| 圓角 | 10～22px 多種 | 4／12／16 三級 |

醜的主要原因推測：

1. **強調色太多**：青、紅、加上四個桌布色塊，畫面沒有主角。抖音只有一個紅。
2. **青色當主色**：青色在抖音裡只是 logo 疊影的一部分，單獨拿來當按鈕色，會顯得像 TikTok 的仿製品，而且跟紅色錄製狀態搶眼。
3. **灰階太藍、太冷**：`#596277`、`#9AA3B6` 這種帶藍的實色灰，在玻璃上看起來髒。抖音的灰幾乎是中性，次要文字直接用透明度，放在任何底色上都乾淨。
4. **語義色不一致**：錄製和錯誤共用一個紅；成功／警告的淺色版偏暗沉。

## 七、可選的改善方向（待 Leo 決定）

以下是方向，不是決定。玻璃效果是硬性約束，保留在共用 CSS 裡。

1. **單一強調色**：主色改為 `#FE2C55` 系（hover `#D21B46`、active `#A50E37`）。青色從介面移除，或只留給極少數點綴。
2. **錄製狀態用直播漸層**：「錄製中」標籤和脈衝點用 `#FF1764 → #ED3495`，跟主要按鈕的紅區分開。
3. **中性底色**：深色採 `#161823` 系或純灰 `#161616` 系其中一個；淺色採 `#F9F9FA`／`#F2F2F4`／`#E4E4E6`。桌布四色改為中性或拿掉。
4. **文字四級透明度**：t1 .9、t2 .75、t3 .6、t4 .34（淺色用 `#161823` 為底色）。
5. **語義色**：成功 `#13C15A`、警告 `#FF851D`、錯誤 `#FF4C13`，兩個模式共用。
6. **圓角收斂**為 4／12／16。

需要先確認的取捨：

- 深色要用帶藍的 `#161823`（抖音主站）還是純灰的 `#161616`（抖音直播站）？
- 青色要完全拿掉，還是保留一點作為「直播中／可錄」的點綴（抖音自己用淺藍 `#8CE7FF` 做直播文字）？
- 介面是否要預設深色？目前跟隨系統。
- 太像抖音官方可能讓人誤以為是官方產品；可以考慮主色沿用紅色系，但不完全複製版面和 logo。
