## 簡介

SupaLive 是一款桌面端的抖音直播錄製工具。它直接保存直播間的原始串流，不經過螢幕錄製或重新編碼，錄下來的畫質與直播一致，也不依賴 FFmpeg。

## 功能特性

- **貼網址錄製**：貼上直播間網址或抖音 App 的分享文字，自動抓取各種畫質供選擇。
- **原畫質保存**：只重新封裝，不重新編碼，支援 H.264 與 HEVC。
- **多路同時錄製**：多個直播間同時錄製，互不影響；同時超過 2 路時提醒風控風險。
- **邊錄邊看**：錄製中可直接播放，支援回看最近約 3 分鐘，並顯示即時碼率與幀率。
- **分段保存**：存成分段式 MP4，錄製中斷也不會損壞已寫入的內容。
- **斷線重連、自動合併**：斷線後自動重連，錄製結束後自動合併分段。
- **降低磁碟寫入**：資料先緩存在記憶體，緩衝大小可調。
- **錄製管理**：按直播間、錄製時間分層整理，自動保存封面；刪除時預設移到廢紙簍。
- **多語言**：支援正體中文與英文，預設跟隨系統。

## 快速開始

### 下載

目前尚未發佈預構建版本，請從原始碼建置。

### 從原始碼建置

需要 Rust 1.88 以上，以及 Tauri 的命令列工具：

```sh
cargo install tauri-cli --version "^2" --locked
cd apps/desktop/src-tauri
cargo tauri build
```

更多說明（包括命令列版）見[開發文件](docs/DEVELOPMENT.md)。

## 使用方法

1. 點擊「新增直播間」，貼上直播間網址。
2. 在右側「選取直播」中選擇畫質，點擊「錄製這個畫質」。
3. 錄製的檔案預設保存在 `下載/SupaLive/<直播間名>/<錄製時間>/`。

連結過期後，點擊「重新抓取連結」即可重新取得。

## 常見問題

**Windows 上無法播放錄製中的畫面？**

HEVC 直播需要安裝「HEVC 視訊延伸模組」才能在 App 內播放。錄製本身不受影響，檔案可以用其他播放器打開。

**同時錄製多少個直播間比較安全？**

程式本身不限制數量，但同時超過 2 個可能觸發抖音風控，導致拉流被暫時封鎖。如果開始頻繁斷線，請減少同時錄製的數量。

**支援 Linux 嗎？**

Linux 可以編譯執行，但部分功能不正常，目前不是支援的平台。
